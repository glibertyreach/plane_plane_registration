[Heading1 L0#1] Review
[p] We take the general formula satisfied by the points  $p_{i}$  on a plane  $v$  to be
[p]  $v⋅p_{i}=(a ; b ; c ; d)^{t}⋅(x_{i} ; y_{i} ; z_{i} ; 1)=ax_{i}+by_{i}+cz_{i}+d=0$ 
[Caption] Equation  – The Plane Equation
[p] The equation satisfied by a thin plane  $o$  affixed at J6, parallel to J6, expressed in the robot’s tool coordinate system (denoted by superscript ‘r’) is
[p]  $o⋅p_{i}^{r}=(0 ; 0 ; 1 ; 0)^{t}(x^{r} ; y^{r} ; z^{r} ; 1)=0⟺z^{r}=0$ 
[Caption] Equation  – Plane Equation for the Robot’s J6 Face
[Heading1 L1#1] Planes not at J6 in Robot Tool Coordinates
[p] Equation 2 is written under the assumption that the target plane is parallel to J6, so its equation, in the robot’s tool coordinate system, is simply  $z^{r}=0$ . This simplifying assumption may not be true, so we will present Equation 2 for the general case.
[p] If the plane is parallel to J6 and has some non-zero thickness  $σ$  then
 $o⋅p_{i}^{r}=(0 ; 0 ; 1 ; -σ)^{t}(x^{r} ; y^{r} ; z^{r} ; 1)=0⟺z^{r}=σ$ 
[Caption] Equation  – Plane Equation for a plane offset to the J6 Face
[p] If the plane  $o$  is affixed at an arbitrary orientation and position with respect to robot tool coordinates, we must write
[p]  $o⋅p_{i}^{r}=(a_{o} ; b_{o} ; c_{o} ; d_{o})^{t}(x^{r} ; y^{r} ; z^{r} ; 1)=a_{o}x^{r}+b_{o}y^{r}+c_{o}z^{r}+d_{o}=0$ 
[Caption] Equation  - Arbitrary Plane in Robot Tool Coordinates
[Heading1 L1#1] A Plane in the Sensor Coordinate System
[p] In the sensor coordinate system ‘ $s$ ’ the equation of a plane is
[p]  $p^{s}⋅p_{i}^{s}=(a ; b ; c ; d)^{t}⋅(x_{i}^{s} ; y_{i}^{s} ; z_{i}^{s} ; 1)⟺ax_{i}^{s}+by_{i}^{s}+cz_{i}^{s}+d=0$ 
[Caption] Equation  – Plane Equation in Sensor Coordinates
[p] Where the superscript ‘ $s$ ’ denotes coordinates measured in the sensor coordinate system.
[p] 

[Heading1 L0#1] Elaboration
[p] We seek the rigid transformation  $X$  which, when applied to a point in sensor coordinates, gives a point in robot (world) coordinates:
[p]  $X⋅p^{s}=p^{w}$ 
[Caption] Equation  – Transform from Sensor to World Coordinates
[p] Suppose a sensor views a plane  $o$  affixed to J6, which is moved to a series of poses  ${T_{1},…,T_{n}}$ . The index  $k$  identifies members of the series of poses: e.g.  $T_{k}: 1≤k≤n$  is a pose in this series.
[p] Suppose, further, the sensor measures the plane coordinates of  $o$  in its own coordinate system to obtain a series of planes  ${p_{1}^{s},…,p_{n}^{s}}$  expressed in the sensor coordinate system ‘s’. As above  $p_{k}^{s}:1≤k≤n$  is a plane in this series.
[p] As  $k$  varies, we can write the following series of equations to relate the plane coordinates

[p]  $P⋅ξ=τ$

[Heading1 L0#1] A Numerically Superior Method
[p] The method for solving for  $Ξ$  and  $X$  in Section 2.2 above does not attempt to enforce the requirement that the rotation submatrix within  $Ξ$  should be orthogonal and properly scaled. If  $Ξ$  can be computed from the least-squares solution to a series of linear equations of the form  $A⋅X=B$  where  $X$  and  $B$  are augmented matrices of ‘N’ homogeneous points and  $A$  is a rigid transform then we can use the mechanisms in the RigidTransform3D class to find  $Ξ$  – while ensuring that the rotation submatrix of  $Ξ$  is properly orthogonal and scaled.
[p] To keep the notation compact, with reference to the RHS of Equation 8, we define
[p]  $(t_{1} ; t_{2} ; t_{3} ; t_{4})_{k}=(τ_{11}_{k}a_{o}+τ_{12}_{k}b_{o}+τ_{13}_{k}c_{o} ; τ_{21}_{k}a_{o}+τ_{22}_{k}b_{o}+τ_{23}_{k}c_{o} ; τ_{31}_{k}a_{o}+τ_{32}_{k}b_{o}+τ_{33}_{k}c_{o} ; τ_{41}_{k}a_{o}+τ_{42}_{k}b_{o}+τ_{43}_{k}c_{o}+d_{o})$ 
[Caption] Equation  - Short Form for RHS Constants,indexed by’k’

[p] Also, we write:
[p]  $p_{k}^{s}=(p_{k}^{s}_{1} ; p_{k}^{s}_{2} ; p_{k}^{s}_{3} ; p_{k}^{s}_{4})=(p_{1}^{s} ; p_{2}^{s} ; p_{3}^{s} ; p_{4}^{s})_{k}$

 $X=X^{t}^{t}=([(R^{-1})^{t} & s \\ \acc(̅){0}^{t} & 1])=([R & s \\ \acc(̅){0}^{t} & 1])∎$

[Heading1 L0#1] Aside: Plane-Plane Transformations
[p] Suppose we have a plane with coefficients expressed in our original coordinate system:  $p=(a ; b ; c ; d)$ . 
[p] The set of points  $p_{i}=(x_{i} ; y_{i} ; z_{i} ; 1)$  lying on the plane all satisfy the equation:
[p]  $p^{t}⋅p_{i}=([a & b & c & d])⋅(x_{i} ; y_{i} ; z_{i} ; 1)=ax_{i}+by_{i}+cz_{i}+d=0$ 
[Caption] Equation  – The Plane Equation
[p] Suppose we have a rigid transformation  $T$  from the original coordinate system into a new coordinate system. We know points are transformed into the new coordinate system by applying the rigid transformation
 $p_{i}^{'}=Tp_{i}$ 
[Caption] Equation  – Rigid Transformation
[p] How do we transform a plane into the new coordinate system so that the new plane  $p'$  satisfies the equation  $p^{'}^{t}⋅p_{i}^{'}=0$ ?
[p] Here’s the trick
[p]  $p^{t}⋅p_{i}=0                         [from above]p^{t}(T^{-1}T)p_{i}=0              [inserting an identity](p^{t}T^{-1})⋅(Tp_{i})=0       [rearranging]((T^{-1})^{t}p)^{t}⋅(Tp_{i})=0  [property of transpose]p^{'}^{t}⋅p_{i}^{'}=0                        [now in the primed coordinate system]$ 
[Caption] Equation  – Showing How Planes are Transformed
[p] Thus, comparing  $p^{t}$  with  $((T^{-1})^{t}p)^{t}$ , we see that the coefficients of the new plane in the new coordinate system are  $(T^{-1})^{t}p=p'$ . 
[p] That is, the old plane  $p$  becomes a new plane  $p'$  by transforming its coefficients by  $(T^{-1})^{t}$ .
[p]  $p^{'}=(T^{-1})^{t}p∎$ 
[Caption] Equation  – Transform Planes via the Inverse Transpose
